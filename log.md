## Project Architecture

### Goal
Build a native macOS app that:
- Uses **Swift UI** for the interface (native macOS window)
- Runs **Node.js backend** with Claude Agent SDK (TypeScript)
- Communicates via stdin/stdout pipes

### Why This Architecture?
- Swift cannot run Claude Agent SDK directly
- Claude Agent SDK only available in TypeScript/Python
- Solution: Native Swift UI + Node.js backend subprocess

### Two UIs in Project

1. **Swift Native UI** (ClaudeChatMac/ContentView.swift)
   - Beautiful native macOS interface
   - Welcome screen with "Think It. Type It. Launch It."
   - Chat view with message history
   - Currently NOT being used by build-app.sh

2. **HTML/CSS/JS Web UI** (Generated by build-app.sh)
   - Created by build script
   - Served at `http://localhost:3030`
   - Opens in Safari/Chrome browser
   - Currently active (the problem we're fixing)


**Result**: App launches browser instead of showing native Swift window.

## Xcode Build Instructions

### Prerequisites
- macOS compatible with Xcode 15.0+
- Node.js installed (required for backend)
- ANTHROPIC_API_KEY available

### Step 1: Add Backend Folder to Xcode

1. Open Xcode project:
   ```bash
   cd /Users/amogh10/Downloads/Friday_AI_git
   open ClaudeChatMac.xcodeproj
   ```

2. In Xcode left sidebar, **right-click** "ClaudeChatMac" folder (blue icon)

3. Select **"Add Files to 'ClaudeChatMac'..."**

4. Navigate to and select the **`backend`** folder

5. **CRITICAL OPTIONS**:
   - ✅ **"Create folder references"** (MUST be blue folder, NOT yellow group)
   - ❌ **"Copy items if needed"** - UNCHECK (we want reference, not copy)
   - ✅ **Target: "ClaudeChatMac"** - CHECK

6. Click **"Add"**

### Step 2: Configure API Key in Xcode

1. **Product** → **Scheme** → **Edit Scheme...**
2. Select **"Run"** (left sidebar)
3. Click **"Arguments"** tab (top)
4. Under **"Environment Variables"**, click **+**
5. Add:
   - **Name**: `ANTHROPIC_API_KEY`
   - **Value**: `sk-ant-...` (your actual API key)
6. Click **"Close"**

### Step 3: Build and Run

1. Select target: **"My Mac"** (top toolbar)
2. Click **▶️ Play button** or press **Cmd+R**
3. App should build and launch as native macOS app with Swift UI

## Backend Communication Flow

### Swift → Node.js (Query)

1. User types message in Swift UI
2. `ClaudeService.sendMessage()` called
3. Creates JSON: `{"type": "query", "message": "user text"}`
4. Writes to `inputPipe` (Node.js stdin)

### Node.js → Swift (Response)

1. `backend/claude-server.js` reads from stdin
2. Calls Claude Agent SDK via `query()` function
3. Streams responses as JSON to stdout:
   - `{"type": "chunk", "text": "partial response"}`
   - `{"type": "complete", "result": "..."}`
   - `{"type": "error", "message": "error text"}`
4. Swift reads from `outputPipe`, updates UI in real-time

### Claude Agent SDK Features

- Uses `@anthropic-ai/claude-agent-sdk` (npm package)
- Model: `claude-sonnet-4-5`
- MCP Server: `@modelcontextprotocol/server-filesystem`
- Allowed paths: User's home directory
- Permission mode: Configured per user needs

## Known Issues & Solutions

### Issue 1: "Browser opens instead of native app"
**Cause**: Using `build-app.sh` instead of Xcode build
**Solution**: Follow Xcode build instructions above

### Issue 2: "Node.js not found"
**Error**: `Node.js not found` in console
**Solution**: Ensure Node.js installed at standard paths:
- `/usr/local/bin/node`
- `/opt/homebrew/bin/node`
- `/usr/bin/node`

### Issue 3: "Backend file not found"
**Error**: Cannot find `claude-server.js`
**Solution**: Ensure backend folder added to Xcode as folder reference (blue, not yellow)

### Issue 4: "ANTHROPIC_API_KEY not set"
**Error**: API key missing
**Solution**: Set in Xcode scheme environment variables (Step 2 above)

### Issue 5: "Module not found" (Node.js)
**Error**: `Cannot find module '@anthropic-ai/claude-agent-sdk'`
**Solution**:
```bash
cd backend
npm install
```
